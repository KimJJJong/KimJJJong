## 한국어

게임에 대한 흥미를, 직접 게임을 만들고 다른 사람에게 플레이해 보게 하며 개선하는 행동으로 옮기는 게임 서버 개발자입니다.

C#/.NET으로 게임 서버를 만들고 있습니다. ASP.NET Core API, gRPC ControlPlane, TCP GameServer를 나누어 인증·세션·Room 수명주기를 구현했으며, `SocketAsyncEventArgs` 기반 서버 코어와 논리 Tick 결과 동기화를 직접 다뤘습니다. PostgreSQL·Redis·Docker 환경을 구성하고 테스트와 구조화 로그로 동작을 확인합니다.

### 대표 프로젝트

- [Pulse World](https://github.com/KimJJJong/Pulse_World) — 리듬 액션 RPG의 Ticket·Presence 기반 게임 서버
- [WAR'LD Painting Server](https://github.com/KimJJJong/RTS_Server) — 1:1 실시간 PvP를 위한 .NET 8 서버
- [RTS Log Monitoring Config](https://github.com/KimJJJong/rts-log-monitoring-config) — Filebeat·Elasticsearch·Kibana 로그 파이프라인

## 日本語

ゲームへの興味を、自らゲームを作り、人に遊んでもらい、改善する行動へつなげているゲームサーバー開発者です。

C#/.NETでゲームサーバーを開発しています。ASP.NET Core API、gRPC ControlPlane、TCP GameServerを分離し、認証・セッション・Roomのライフサイクルを実装しました。`SocketAsyncEventArgs`ベースのサーバーコアと論理Tickによる結果同期を扱い、PostgreSQL・Redis・Dockerの環境を構成しています。テストと構造化ログを用いて動作を確認しています。

### 主なプロジェクト

- [Pulse World（日本語）](https://github.com/KimJJJong/Pulse_World/blob/portfolio-public-cleanup/README.ja.md) — Ticket・Presenceを用いたリズムアクションRPGのゲームサーバー
- [WAR'LD Painting Server（日本語）](https://github.com/KimJJJong/RTS_Server/blob/main/README.ja.md) — 1対1リアルタイムPvP向け.NET 8サーバー
- [RTS Log Monitoring Config（日本語）](https://github.com/KimJJJong/rts-log-monitoring-config/blob/main/README.ja.md) — Filebeat・Elasticsearch・Kibanaによるログパイプライン
